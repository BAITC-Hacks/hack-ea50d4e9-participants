# Career Quest

Локальное веб-приложение для хакатонного кейса HackAlem AI: объяснимые рекомендации по развитию сотрудника, пересчёт навыков после активности и HR-аналитика. Исходный набор синтетический. Репозиторий никуда автоматически не отправляет данные.

## Быстрый запуск

Нужен Docker Desktop с запущенным Linux engine.

1. Скопируйте `.env.example` в `.env`: в PowerShell `Copy-Item .env.example .env`.
2. При необходимости заполните ключи OpenAI и/или NVIDIA в `.env`. Без них рекомендации работают на прозрачном локальном ранжировщике.
3. Запустите `docker compose up --build -d` из корня проекта.
4. Откройте [http://localhost:8000](http://localhost:8000). Проверка API: [http://localhost:8000/api/health](http://localhost:8000/api/health); OpenAPI: [http://localhost:8000/docs](http://localhost:8000/docs).

Первый запуск создаёт таблицы PostgreSQL и загружает `data/`: 200 профилей, 40 событий, 60 навыков и 2 743 записи истории. Повторный запуск не дублирует исходные записи. База хранится в Docker volume `postgres_data`; `docker compose down` сохраняет данные. `docker compose down -v` удалит volume и все изменения, поэтому используйте эту команду только если действительно нужен полный сброс.

Приложение привязано к `127.0.0.1` и предназначено для локальной защиты. При конфликте порта задайте `APP_PORT` в `.env`. PostgreSQL снаружи Docker не публикуется.

## Что показать на защите

1. В разделе «Моя траектория» выберите профиль `E0028` или любого другого сотрудника. Видны роль, текущий грейд, следующая веха, покрытие требований и история.
2. Откройте рекомендации. Каждая карточка объясняет, какой разрыв она сокращает, ожидаемый прирост, место в локальном рейтинге, историю похожих активностей и доступность. Когда подходящих активностей нет, система объясняет ограничение каталога и предлагает скопировать конкретный запрос HR по главному разрыву или карьерной цели. Запрос не считается курсом и не повышает навыки. Обязательные мероприятия показаны отдельно.
3. Для самостоятельной активности нажмите «Отметить пройденным». Демо-отметка сохраняется датой среза данных; модельный уровень и рекомендации пересчитываются. Очную или онлайн-активность можно отметить только на дату состоявшейся сессии из каталога, поэтому кнопка будущей сессии неактивна. Отметку из приложения можно отменить в истории участия; исходные записи датасета не удаляются.
4. Переключите роль на HR: доступны дефициты по навыкам, сотрудники с разрывом без доступного шага, сотрудники без карьерной цели и участие по активностям.
5. В разделе «Импорт данных» загрузите JSON с дополнительным сотрудником и/или CSV с историей по той же схеме, что в стартовом наборе. Сначала нажмите «Проверить файлы», затем «Загрузить набор». Импорт атомарный; ошибки отображаются до загрузки.

## Конфигурация `.env`

| Переменная | Назначение |
| --- | --- |
| `APP_PORT` | Локальный порт веб-приложения, по умолчанию `8000`. |
| `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` | База, пользователь и пароль PostgreSQL в Compose. При уже созданном volume смена этих значений сама по себе не меняет существующие учётные данные БД. |
| `DEMO_MODE` | `true` для локального переключателя ролей и профилей. `false` закрывает демо-эндпоинты до подключения настоящего SSO. |
| `AI_PROVIDER` | `auto`, `openai`, `nvidia` или `off`. `auto` пробует OpenAI, затем NVIDIA, затем локальный ранжировщик. |
| `OPENAI_API_KEY`, `OPENAI_MODEL` | Ключ и доступная вашей учётной записи модель OpenAI Responses API. |
| `NVIDIA_API_KEY`, `NVIDIA_MODEL` | Ключ и доступная модель NVIDIA NIM Chat Completions. |
| `AI_TIMEOUT_SECONDS` | Общий бюджет внешнего AI в секундах; по умолчанию `7.5`. |

**Ключи не нужны для запуска.** Если один или оба ключа добавлены, проверьте, что ID моделей доступны именно вашему аккаунту. Их доступность и стоимость зависят от аккаунта и квот. Не коммитьте `.env`; он исключён через `.gitignore`. Запрос к внешнему AI содержит целевой профиль, агрегированные разрывы и обезличенные кандидаты, без имени сотрудника и сырой истории. Проверьте правила хакатона перед включением облачного провайдера. OpenAI используется через [Responses API и Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), NVIDIA — через [NIM Chat Completions](https://docs.api.nvidia.com/nim/re/reference/llm-apis).

## Как устроено решение

- `backend/domain.py` — цели, модельный прогресс, фильтр доступности, прозрачный рейтинг. Фильтр исключает обязательные мероприятия, несоответствие роли/грейду, невыполненные prerequisites, завершённые неповторяемые активности и отсутствие будущей сессии. Если доступная активность не сокращает ни одного разрыва до ближайшей или долгосрочной цели, она не рекомендуется. Исторический фактор учитывает завершения из датасета и из приложения, а также пропуски и отказы по тем же навыкам.
- `backend/ai_provider.py` — AI выбирает и переупорядочивает только допустимых кандидатов. Первым шагом допускается один из трёх лучших по многофакторному локальному рейтингу. Если лучший по рейтингу закрывает критичный разрыв, AI сохраняет этот приоритет; критичность сама по себе не обходит штрафы за историю. Ответ проверяется по ID событий, кодам причин и ссылкам на факты. При ошибке, таймауте или отсутствии ключа работает локальный рейтинг.
- `backend/ingestion.py` — проверка дополнительных JSON/CSV. Исходный набор не перезаписывается; каждый импорт создаёт отдельный batch.
- `backend/database.py`, `backend/schema.sql` — PostgreSQL и идемпотентная первичная загрузка.
- `backend/main.py`, `backend/analytics.py` — HTTP API, демо-доступ, HR-агрегаты (включая завершения из приложения) и раздача собранного интерфейса.
- `frontend/` — React/TypeScript, собранный Vite; Dockerfile собирает интерфейс и включает его в один контейнер приложения.

Дата «сегодня» — `2026-10-01` из метаданных набора, независимо от текущих часов компьютера. `employees.skills` остаётся последней подтверждённой оценкой; завершения после `last_review_date` формируют **модельный** уровень. Для `self_paced` дата в истории означает запись/назначение: если она раньше последней оценки, фактическое завершение неоднозначно и прирост не применяется автоматически. Процент покрывает требования к навыкам, но не означает вероятность повышения.

В локальном демо переключатель ролей находится в UI и технически подделывается заголовками. Это **не корпоративная авторизация**. Перед использованием с реальными данными нужны SSO, реальные права доступа, согласованная политика передачи данных и проверка переводов контента. Каталог мероприятий в наборе на английском; интерфейс первого релиза на русском.


```powershell
docker compose ps
docker compose logs app --tail 100
```
